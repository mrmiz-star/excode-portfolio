## 🧠 Core Philosophy

The **EX CODE Portfolio** is not a student template. It is an **engineering dashboard** designed to communicate technical seniority and operational reliability. Instead of long paragraphs, it uses **Impact Lines** and **Status Badges** to provide instant technical recognition.

> "I build systems that solve real problems. Every card here represents shipped code, battle-tested logic, and production-ready architecture."

---

## 🎴 Project Card Architecture

Each project is presented via a high-authority card system designed for maximum engagement.

### 🧩 Visual Components
- **Status Badge System**: Instant recognition of project lifecycle stage.
    - 🟢 **Production**: Fully working and usable system.
    - 🟡 **In Progress**: Currently being improved or expanded.
    - 🔵 **Concept**: Experimental or architecture-stage project.
- **Dynamic Previews**: 16:9 project images with smooth hover-zoom and glassmorphism overlays.
- **Impact Line**: A single, sharp technical sentence explaining exactly what the project does.
- **Demo Guard**: Integrated fallback system that displays a professional modal for projects with pending walkthroughs.

---

## 🛠️ Tech Stack

- **Frontend**: React 19 + Vite 8 (Ultra-fast HMR and optimized builds)
- **Styling**: Tailwind CSS v4 + Native CSS Glassmorphism
- **Icons**: Lucide React + Custom SVG Brand Icons
- **Animation**: CSS Keyframes + Canvas Particle Engine (40-node graph)
- **Typography**: `Outfit` (Modern UI) & `Share Tech Mono` (Engineering readout)

## 📦 System Sections

1.  **Hero Section**: Canvas-animated particle network with typewriter role cycling.
2.  **Engineering Identity**: High-level focus on architecture, system design, and security.
3.  **Project Grid**: The core engine. Responsive grid (3-col desktop) with category filtering.
4.  **Skills Matrix**: Data-driven technical arsenal visualization.
5.  **Active Development**: Transparency on current refactoring efforts and architectural upgrades.

## ⚙️ Setup & Deployment

### Local Development
```bash
# 1. Initialize
git clone https://github.com/qarizafar12-max/excode-portfolio.git
cd excode-portfolio

# 2. Install
npm install

# 3. Launch
npm run dev
```

### Production Build
```bash
npm run build
```
*Output directory: `/dist`*
