## 🧠 Core Philosophy

The **EX CODE Portfolio** is engineered to showcase production-focused systems, tooling, and real-world architecture through a refined technical interface. Instead of descriptive paragraphs, it utilizes **Technical Impact Lines**, **Interactive Architecture Diagrams**, and **System Status Badges** to provide immediate technical context.

> "I build systems focused on operational reliability and technical depth. Every project documented here represents active engineering work, architecture exploration, or production-focused implementation."

## 🎴 Project Card & Modal Architecture

Each project is documented via a technical card system designed for efficient visual and technical review.

### 🧩 Visual Components
- **Status Badge System**: Instant recognition of project lifecycle stage.
    - 💎 **Production**: Fully working and operational (Cyan/Green Glow).
    - 🟡 **In Progress**: Active development or maintenance.
    - 🔮 **Concept**: Experimental or architecture-stage (Purple Glow).
- **Dynamic Previews**: 16:9 project images with smooth hover-zoom and glassmorphism overlays.
- **Technical Impact Line**: A concise, sharp sentence explaining the core utility and technical scope.
- **Dynamic Metrics Telemetry**: Custom project metrics (e.g. connections, platforms supported, OCR modes) displayed in a distinct metrics strip.
- **Key Features Grid**: Visual breakdown checklist of implementation features.
- **System Architecture Diagrams**: Beautiful interactive React Flow network graphs depicting inputs, processors, and output nodes.

## 🎨 Design System & Theme

The portfolio features a curated, data-driven theme designed for maximum technical authority.

## ⚙️ Setup & Deployment

### Local Development
```bash
# 1. Initialize
git clone https://github.com/qarizafar12-max/excode-portfolio.git
cd excode-portfolio

# 2. Install
npm install

# 3. Launch
npm run dev
```

### Production Build
```bash
npm run build
```
*Output directory: `/dist`*
